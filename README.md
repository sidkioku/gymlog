# GymLog

WebApp für Krafttraining-Tracking, Progressive Overload, Progressions-Charts und Muskel-Heatmap.

## Live-App

👉 **https://sidkioku.github.io/gymlog/**

Auf dem iPhone in Safari über **Teilen → „Zum Home-Bildschirm“** hinzufügbar (inkl. Offline-Nutzung).

## Lokal starten

```bash
npm start
```

Tests ausführen:

```bash
npm test
```
